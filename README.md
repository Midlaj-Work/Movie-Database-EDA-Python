# 🎬 Movie Database Exploratory Data Analysis Using Python

An end-to-end Exploratory Data Analysis (EDA) project using Python to analyze a movie dataset. This project demonstrates data cleaning, feature engineering, data visualization, and business insight generation.

---

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a movie dataset using Python. The dataset was cleaned, transformed, and analyzed to identify trends related to movie genres, popularity, ratings, languages, and release years.

---

## 🎯 Objectives

* Clean and preprocess the dataset
* Handle missing values
* Perform feature engineering
* Analyze movie genres and languages
* Identify the most popular movies
* Identify the highest-rated movies
* Analyze movie release trends
* Generate business insights

## 📈 Key Business Insights

* Drama is the most common movie genre with 466 movies.
* English is the dominant original language with 7,569 movies.
* Spider-Man: No Way Home has the highest popularity score (5083.954).
* Kung Fu Master Huo Yuanjia has the highest average audience rating (10.0).
* Movie releases reached their highest level in 2021 with 714 movies.
